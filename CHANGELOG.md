# Changelog

This project follows [Semantic Versioning](https://semver.org/).

## 0.1.0 — 2026-08-25

- Publish the first CodePhFox reference implementation.
- Add the `ZWM1` checksummed zero-width message codec.
- Add encode, decode, inspect, and capacity CLI commands.
- Add JSON output for agent-friendly inspect and capacity commands.
- Measure transport limits in UTF-16 code units.
- Support macOS, Wayland, X11, and Windows clipboard commands.
- Document the protocol, safety boundary, attribution, and agent workflow.
